# تریدر شو (Trader Show)

پروژه‌ی Android Studio (Kotlin + Jetpack Compose) برای بازی شبیه‌سازی ترید «تریدر شو».

## ⚠️ به‌روزرسانی مهم: خرید درون‌برنامه‌ای از مایکت به کافه‌بازار تغییر کرد

پروژه الان با **پولکی (Poolakey)**، کتابخونه‌ی رسمی خرید درون‌برنامه‌ای کافه‌بازار، کار می‌کنه (نه مایکت). کد بر اساس [مستندات رسمی Kotlin کافه‌بازار](https://developers.cafebazaar.ir/en/guidelines/in-app-billing/implementation/kotlin) نوشته شده، ولی چون من نمی‌تونم پروژه رو واقعاً کامپایل کنم، یه نکته رو حتماً موقع Sync چک کن:

- توی `BillingManager.kt`، داخل `queryPurchasedAndConsumePending()` و `purchaseSucceed`، از `entity.productId` و `entity.purchaseToken` استفاده شده. مستندات رسمی دقیقاً اسم این دو فیلد رو نشون نمی‌داد؛ اگه Android Studio این دو تا رو قرمز نشون داد، `Ctrl+Space` بزن روی اون آبجکت تا اسم واقعی فیلدها رو ببینی و جایگزین کن — بقیه‌ی کد (اسم کلاس‌ها، ساختار callback ها) مستقیم از مستندات رسمیه.
- قبل از تست خرید واقعی، باید این اپ رو از طریق **کافه‌بازار** نصب کرده باشی (نه مستقیم APK)، چون پولکی برای وصل شدن به سرویس خرید نیاز به نصب از طریق بازار داره.

## نحوه‌ی باز کردن پروژه

1. Android Studio را باز کنید، `Open` را بزنید و پوشه‌ی `TraderShow` را انتخاب کنید.
2. صبر کنید Gradle Sync کامل بشه (نیاز به اینترنت داره).
3. Run بگیرید.

## این نسخه چه باگ‌هایی رو رفع کرد

- **کیف پول نامرئی توی حساب کاربری**: علت اصلی این بود که صفحه اسکرول نداشت و چون بازی افقیه (ارتفاع صفحه کمه)، محتوا از پایین صفحه بیرون می‌زد. صفحه بازطراحی و اسکرول‌پذیر شد؛ کیف پول حالا همیشه توی کارت‌های ثابت و واضح نمایش داده می‌شه (دیگه هم قابل تایپ نیست، فقط نمایشیه؛ تبدیل ارز یه بخش جدا با انتخاب جهت مشخصه)
- **بسته‌های IAP دیده نمی‌شدن**: همون علت (نبود اسکرول) — الان رفع شده
- **تبلیغ جایزه‌ای پول نمی‌داد**: `AdManager` با `applicationContext` ساخته می‌شد که باعث می‌شد تبلیغ درست به Activity وصل نشه؛ الان با خود Activity ساخته می‌شه
- **پکیج اشتباه کتابخونه‌ی مایکت**: به `ir.myket.billingclient` (و `ir.myket.billingclient.util` برای بقیه‌ی کلاس‌ها) اصلاح شد
- **نوارهای زندگی من که مغازه رو قایم کرده بودن**: نوارها کوچیک شدن و رفتن گوشه‌ی بالا-راست با رنگ داینامیک (سبز/زرد/قرمز)؛ مغازه حالا کل صفحه رو داره

## چی جدید اضافه شد

- تم و رنگ‌بندی مدرن‌تر (پالت تیره‌ی فین‌تک، فونت خواناتر)
- ناوبری پایین باریک‌تر و شیک‌تر (به‌جای نوار بزرگ استاندارد)
- چارت کندل قابل **زوم (پینچ)** و **پن (کشیدن افقی برای عقب/جلو رفتن)**
- **تایم‌فریم قابل‌انتخاب** برای کندل‌ها: ۱ دقیقه / ۵ دقیقه / ۱ ساعت / ۲۴ ساعت
- امکان **تایپ مقدار دلخواه** برای معامله (علاوه بر دکمه‌های آماده)
- **فیوچرز**: انتخاب اهرم (1x/5x/10x/20x) — با اهرم بالاتر، سود/ضرر و ریسک لیکوییدشدن بیشتر می‌شه (دقیقاً مثل صرافی‌های واقعی)
- **چالش‌های روزانه** (تب جدید «چالش‌ها»): پیشرفت واقعی هر چالش دنبال می‌شه و پاداش تومانی + XP می‌ده
- **سیستم لول/XP**: از بستن پوزیشن‌های سودده و خرید در «زندگی من» XP می‌گیری؛ نوار پیشرفت لول توی حساب کاربری دیده می‌شه و موقع لول‌آپ یه پیام کوچیک نشون داده می‌شه
- گرافیک بهتر برای کارت‌های شارژ حساب (آیکون، گرادیان)

## چیزهایی که هنوز باقی مونده

- آیکون واقعی برنامه (فعلاً placeholder داره)
- Keystore واقعی برای انتشار نهایی
- تست عملی روی دستگاه واقعی برای تأیید نهایی رفع باگ تبلیغات (چون من نمی‌تونم پروژه رو کامپایل/اجرا کنم، این تغییر بر اساس تحلیل دقیق کد بوده، نه اجرای واقعی)

## ساختار پروژه

```
app/src/main/java/ir/amir/triedgame/
  model/         مدل‌های داده (Asset, Wallet, Position با leverage, DailyChallenge, ...)
  engine/        موتور شبیه‌سازی قیمت (PriceEngine)
  data/          پرسیستنس محلی (GameRepository) شامل چالش‌های روزانه
  ads/           رَپر Adivery (AdManager) — حالا با Activity context
  billing/       رَپر مایکت (BillingManager) — پکیج import اصلاح‌شده
  ui/            ViewModel، ناوبری مدرن، و همه‌ی صفحات Compose
```

هر باگ دیگه‌ای دیدی، دقیقاً مثل قبل (اسکرین‌شات + توضیح) بفرست.
